How we worked it out

The reasoning and the in-game runs behind the numbers above.

Every speed on these pages is worked out from engine revs and the gearing alone:

speed (km/h) = rpm × tyre circumference (m) × 0.06 ÷ total ratio

rpm × tyre circumference ÷ total ratio is metres per minute; × 0.06 (× 60 minutes per hour ÷ 1000 metres per kilometre) turns that into km/h.

total ratio = primary × gear × final drivetyre circumference = 2π × free radius × 0.9780

The free radius is the tyre radius stored in the game files. The rolling factor, 0.9780, allows for a loaded tyre rolling on a slightly smaller radius; it was fitted to the top speeds measured in game on 15 runs across eight cars (Stratos, 306 Maxi, Xsara WRC, 037, 206 WRC, Delta Integrale, Impreza and GTA Junior).

The rev limit, 6760 rpm, was measured in game with telemetry. The end of the torque curve in the game files is not the limiter: on most cars here the curve runs past it.

On the Impreza no ratio is applied before the centre differential. The front path has Differential Ratio Front; the rear path has Center Ratio to Rear and Differential Ratio Rear:

front path ratio = Differential Ratio Frontrear path ratio = Center Ratio to Rear × Differential Ratio Rear

With all four wheels turning at the same road speed, the centre differential's input turns at (front output speed + rear output speed) ÷ 2, so the equivalent final drive is:

final drive = (front path ratio + rear path ratio) ÷ 2final drive = (Differential Ratio Front + Center Ratio to Rear × Differential Ratio Rear) ÷ 2

The first run was chosen to distinguish between:

  1. Final drive = front path ratio alone.
  2. Final drive = rear path ratio alone.
  3. Final drive = (front path ratio + rear path ratio) ÷ 2.

It was run on Differential Ratio Front 36//7 and Differential Ratio Rear 31//9, with Center Ratio to Rear on 31//31, a ratio of 1. The three possibilities put 5th at about 128, 191 and 153 km/h. The speedometer read 155, supporting final drive = (front path ratio + rear path ratio) ÷ 2.

The second run was chosen to distinguish between:

  1. Center Ratio to Rear multiplies: rear path ratio = Center Ratio to Rear × Differential Ratio Rear.
  2. Center Ratio to Rear is ignored: rear path ratio = Differential Ratio Rear.
  3. Center Ratio to Rear divides: rear path ratio = Differential Ratio Rear ÷ Center Ratio to Rear.

It was run on Differential Ratio Front 31//9, Center Ratio to Rear 22//28 and Differential Ratio Rear 48//11. If Center Ratio to Rear multiplies, these keep the two path ratios nearly equal. The three possibilities put 4th at about 162, 143 and 124 km/h. The speedometer read 164, supporting rear path ratio = Center Ratio to Rear × Differential Ratio Rear. With the path ratios nearly equal the car drove normally, as expected.
