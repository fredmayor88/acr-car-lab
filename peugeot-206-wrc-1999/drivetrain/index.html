How we worked it out

The reasoning and the in-game runs behind the numbers above.

Every speed on these pages is worked out from engine revs and the gearing alone:

speed (km/h) = rpm × tyre circumference (m) × 0.06 ÷ total ratio

rpm × tyre circumference ÷ total ratio is metres per minute; × 0.06 (× 60 minutes per hour ÷ 1000 metres per kilometre) turns that into km/h.

total ratio = primary × gear × final drivetyre circumference = 2π × free radius × 0.9904

The free radius is the tyre radius stored in the game files. The rolling factor, 0.9904, allows for a loaded tyre rolling on a slightly smaller radius; it was fitted to the top speeds measured in game on 14 runs across seven cars (Stratos, 306 Maxi, Xsara WRC, 037, 206 WRC, Delta Integrale and Impreza).

The rev limit, 7400 rpm, was measured in game with telemetry. The end of the torque curve in the game files is not the limiter: on every car here the curve runs past it.

The 206 has no engine curve of its own: its car data in the game files points at the Xsara WRC's, so that is the curve used here.

On the 206, Center Differential Ratio is applied before the centre differential. The front path adds Differential Ratio Front and the rear path Differential Ratio Rear:

front path ratio = Center Differential Ratio × Differential Ratio Frontrear path ratio = Center Differential Ratio × Differential Ratio Rear

With all four wheels turning at the same road speed, the centre differential's input turns at (front output speed + rear output speed) ÷ 2, so the equivalent final drive is:

final drive = (front path ratio + rear path ratio) ÷ 2final drive = Center Differential Ratio × (Differential Ratio Front + Differential Ratio Rear) ÷ 2

Its gear sets store a primary of 20//25, which is not one of the three Primary Gear steps. The first two runs distinguish between:

  1. The Primary Gear you pick replaces the stored primary: primary = Primary Gear.
  2. The stored primary still applies: primary = 20//25.

Gear set 1 was run on Primary Gear 21//24 and gear set 3 on 22//24. On gear set 1 the predictions for 3rd were about 126 km/h with primary = Primary Gear and 137 km/h with primary = 20//25. The speedometer read 127. Across the gears, 20//25 would have put the speeds about 8% too high on gear set 1 and 14% too high on gear set 3, supporting primary = Primary Gear.

The third run was chosen to distinguish between:

  1. Center Differential Ratio multiplies the whole final drive.
  2. Center Differential Ratio does not change the gearing.

It repeated the second run with Center Differential Ratio on 31//21 (1.476) instead of 24//24 (a ratio of 1). The predictions for 5th were about 97 km/h if it multiplies and 144 km/h if it changes nothing. The speedometer read 98, and across the gears the speeds dropped by a factor of about 1.47 from the second run, supporting possibility 1: Center Differential Ratio multiplies the whole final drive.

The last run was chosen to distinguish between:

  1. Final drive = front path ratio alone.
  2. Final drive = rear path ratio alone.
  3. Final drive = (front path ratio + rear path ratio) ÷ 2.

It was run on gear set 3 with Primary Gear 22//24, Center Differential Ratio 24//24, Differential Ratio Front 43//13*21//13 and Differential Ratio Rear 40//18*26//16. The three possibilities put 4th at about 117, 174 and 140 km/h. The speedometer read 142, supporting final drive = (front path ratio + rear path ratio) ÷ 2.
